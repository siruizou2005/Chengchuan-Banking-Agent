为向你提供智能助手服务，澄川银行（以下称「本行」）需要处理你的部分个人信息。请在开通前仔细阅读本授权书。澄川银行为模拟环境，所有数据均为虚拟数据。

## 一、处理的信息及用途

| 信息 | 用途 |
| --- | --- |
| 账户余额、交易与流水 | 回答余额查询，生成账单分析、消费统计和异常提醒 |
| 理财持仓与风险测评等级 | 产品对比、配置建议和适当性匹配 |
| 卡片、贷款、信用卡、订阅与收款人 | 卡片管理、还款、订阅管理和转账收款人识别 |
| 对话内容与语音转写文本 | 理解你的请求并生成回复，保存为对话历史供你查看 |
| 称呼、偏好与理财目标等个性化记忆 | 按你的习惯组织回答 |
| 飞书、微信渠道标识 | 在你绑定的渠道中收发消息 |

## 二、委托处理与对外提供

1. 为生成回复，对话内容与回答所需的账户摘要会发送给本行委托的大语言模型服务商处理。发送前会对证件号、完整卡号、手机号、密码和验证码等信息做脱敏。
2. 语音输入会发送给语音识别服务商转写为文字，原始音频不保存。
3. 为完善账单分类，本行每日会把关键词无法识别的商户名称发送给上述大语言模型服务商判断消费类别。发送内容仅为商户名称，不含你的身份、金额、时间和账号，也不发送个人姓名。分类结果按商户保存，供本行所有用户共用。
4. 你打开隐形消费分析时，本行会把当月消费的日期、金额、分类、支付渠道和商户名称，以及此前 6 个月同商户的出现月数，发送给上述大语言模型服务商识别隐形消费。发送内容不含你的身份和账号，也不发送个人姓名。
5. 除上述委托处理外，本行不会向第三方提供你的个人信息。

## 三、保存期限

1. 对话历史、个性化记忆和隐形消费分析结果保存至你删除或关闭智能助手时选择清空为止。
2. 操作审计记录按监管要求保留，不随关闭或清空删除。

## 四、你的权利

1. 你可以在「我的 → 个性化与记忆」查看、更正和删除个性化记忆，在智能助手中删除对话历史。
2. 你可以随时在「安全中心」关闭智能助手并撤回本授权；撤回不影响撤回前已进行的处理。
