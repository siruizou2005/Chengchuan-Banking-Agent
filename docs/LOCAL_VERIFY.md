**1. 启动项目**

在项目目录打开终端，确认使用 **Node.js 24 或更新版本**：

```sh
node -v
npm ci
npm run dev
```

仅测试这两个验证流程，不需要配置聊天模型 API Key。

**3. 触发加强验证**

进入：

**我的 → 安全中心 → 每日转账限额**

将限额调高，例如从 **50,000 元改为 60,000 元**，点击“下一步”。必须高于当前限额，才会触发这项操作的加强验证。

**4. 完成人脸模拟**

点击“开始验证并发送验证码”，然后：

- 点击“开启摄像头并采集”，允许浏览器使用摄像头。
- 等待约 2 秒，系统保存画面摘要，进入验证码步骤。
- 如果摄像头不可用，可点击“记录降级并继续短信验证”。

此步骤只演示摄像头采集，不进行真实身份比对。

1. 点击“打开模拟短信收件箱”。
2. 找到最新消息中的六位验证码。
3. 在 5 分钟内输入，点击“验证短信，继续支付密码”。

看到“设置已更新”，就完成了整个加强验证流程。
