## 结论的适用范围

本次证明了在指定的“较新无关记录挤出较早偏好”数据集中，新检索能保留目标偏好，并将提示限制在预算内；完整 Agent、工具回路和管理页面已经使用新实现。开发中发现并修复了模块匹配导致低重要性备注占满预算的问题。

**没有证明整体 Token 费用下降。** 小数据下新旧 Memory 字节相同，新增 Skill 和数据边界说明使新方案总输入增加；C 还增加了少量展示提示。实际供应商分词、缓存计费和回答质量需接入真实模型后测量。不能以 A 在大数据样本中漏掉全部记忆、输入更短作为其质量更优的证据，也不能将当前合成样本结果外推到所有记忆分布。

未执行的验收：真实微信/飞书端到端平台联调、真实模型的专业分析与遵循效果、长期用户数据上的错误率和偏好质量、连续 24 小时实际空闲审计。当前只有受控模拟渠道测试与空闲零调用测试通过。
